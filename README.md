# Portfolio · Gloria Curado

Mi portfolio personal, que he hecho para buscar trabajo como Front End Developer. Aquí cuento quién soy, mi experiencia (vengo de la dirección de arte) y los proyectos en los que he trabajado.

Está en español e inglés, y se puede descargar mi CV en los dos idiomas.

**Web:** [gloriacurado.com](https://gloriacurado.com)

## Qué tiene

- Presentación y sección "sobre mí"
- Experiencia y formación
- Carrusel de proyectos que se puede arrastrar
- Página propia para MOLegalSuite, la app que desarrollé para el despacho Morán Ortiz Abogados
- Formulario de contacto
- Cambio de idioma ES / EN

## Tecnologías

- React
- TypeScript
- Vite
- CSS Modules
- Framer Motion para las animaciones
- React Router
- FormSubmit para el formulario de contacto
- Desplegado en Vercel

## Arrancarlo en local

```bash
npm install
npm run dev
```
